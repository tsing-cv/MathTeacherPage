# 高中数学老师微信招生单页视觉规范

设计基准：iPad 4:3（1024×768），适配手机微信内置浏览器（375–430px）。调性：严谨而不冰冷、深厚而不枯燥、精英感与亲和力并存。双受众：家长（信任感）＋高中学生（不老气）。

## 1. 配色 Token（HEX / 场景 / 占比）

| Token | HEX | 场景与占比 |
|---|---|---|
| 深空蓝 bg-base | #0E2140 | 主背景，首屏/尾屏/深底区，50% |
| 层叠蓝 bg-card | #16305C | 深底内卡片、引言块，12% |
| 冷纸白 bg-paper | #F4F7FA | 浅色区块（青灰白，非奶油），22% |
| 金·亮 gold-hi | #E3C88A | 深底大数字/金字，对比≈9.8:1，1% |
| 金·主 gold | #C9A961 | 线条、描边、图标、1px分隔线，仅装饰，3% |
| 金·暗 gold-deep | #8C6F3A | 浅底金（限≥18px或加粗），≈4.4:1，1% |
| 墨蓝 ink | #1B2A44 | 浅底正文，≈13:1 |
| 雾白 snow | #E8EDF5 | 深底正文，≈13:1 |
| 灰蓝 gray-d / gray-l | #8FA0BC / #5A6B85 | 深/浅底辅助文字，≈6:1 / 5:1 |

金色总面积≤5%；实心金仅主CTA按钮（小面积）与小数字，其余一律描边。全部文字色对已按 WCAG AA 验算。

## 2. 字体

- 标题衬线：`"Songti SC","STSong","Noto Serif CJK SC","Source Han Serif SC",serif`（iOS命中宋体；Android微信XWeb命中Noto Serif或降级sans，可接受；Hero标题可导出内联SVG保证跨端一致）
- 正文：`-apple-system,"PingFang SC","HarmonyOS Sans SC","MiSans","Noto Sans CJK SC",sans-serif`
- 数字/西文：`Georgia,"Times New Roman",serif` ＋ `font-variant-numeric:tabular-nums; font-feature-settings:"tnum"`（年份、统计数据统一使用）
- 字号阶梯（1024 / 375，px）：
  - Hero：56 / 34，衬线，字重600，行高1.2
  - H2：32 / 24，衬线600
  - 眉题：14 / 12，无衬线500，letter-spacing 0.2em
  - 正文：17 / 15，行高1.75 / 1.7
  - 辅助：13 / 12，灰阶

## 3. 版式与栅格

首屏（1024×768）Hero 区线框：

```
┌─────────────────────────────────────────┐
│顶栏72px：标识│··导航··│咨询按钮(金描边)    │
├─────────────────────┬───────────────────┤
│左60% 边距96px        │右40%              │
│ 金色眉题13px         │ canvas金色曲线     │
│ Hero衬线56px×2行     │ ＋坐标纸网格       │
│ 副文17px灰蓝         │                   │
│ 数据行(20年/10万+题) │                   │
│ [主CTA金底][次CTA描边]│                   │
├─────────────────────┴───────────────────┤
│ 信任条64px／滚动指示                     │
└─────────────────────────────────────────┘
```

- 网格：12栏，gutter 24px；页边距 96px（iPad）/ 20px（手机）；区块垂直间距 96 / 48px
- 深浅交替：深首屏→浅教研体系→深课程与数据→浅师资→深CTA尾屏；交界处 1px 金线（gold @40%）横向贯穿，形成"装订线"仪式感

## 4. 数学元素艺术化

- Hero canvas：f(x) = 60·sin(x/90) + 24·sin(x/31 + π/3)，x∈[0,1024]，gold 1.5px 描边自左向右画出；另叠一条相位差残影曲线 opacity 0.25
- 坐标纸网格纹理：32×32px 格，1px 线；深底 gold @0.06、每4格加重线 @0.10；浅底 gold-deep @0.08；CSS 双 linear-gradient 实现
- 低透明度数学符号：全页仅 2 处——浅底"教研体系"区右下 ∑（约480px，衬线，opacity 0.04，出血裁切）、深底 CTA 区 ∫ 同参数；禁止平铺、禁止与正文重叠

## 5. 微交互清单

| 交互 | 触发 | 时长 | 缓动 | reduced-motion |
|---|---|---|---|---|
| Hero入场编排（眉题→标题→副文→曲线→数字，0/80/160/300/600ms错峰） | load | 单项400–600ms | cubic-bezier(.65,0,.35,1) | 立即全显 |
| 曲线描画 | load+300ms | 1800ms | 同上 | 呈现终态 |
| 数字滚动 | 首次入视口 | 1200ms | cubic-bezier(.16,1,.3,1) | 直接渲染终值 |
| 卡片组入场（整组一次，stagger 80ms，translateY 24→0） | 首次入视口 | 600ms | cubic-bezier(.22,1,.36,1) | 禁用 |
| 金线/按钮hover | hover | 200ms | ease-out | 保留 |

原则：全页编排仅发生在首屏一次；滚动区块最多整组一次入场（IntersectionObserver 命中即 unobserve），杜绝逐块 fade-in 的模板感。
