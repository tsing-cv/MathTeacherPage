# 微信分享卡优化、防拦截与转化路径完整方案

适用项目：独立高中数学老师个人招生宣传单页（纯静态 HTML，二维码 + 微信分享传播；受众：高中生家长+学生；转化目标：添加老师微信咨询/预约试听）。

## 一、Meta 标签清单与微信分享机制

```html
<title>高中数学提分，先试听再决定</title>
<meta name="description" content="40字内摘要">
<meta property="og:title" content="同标题">
<meta property="og:description" content="同摘要">
<meta property="og:image" content="https://你的备案域名/share-500x400.png">
<meta property="og:url" content="https://你的备案域名/">
<meta property="og:type" content="website">
```

**未接 JSSDK 的现实行为**：微信卡片标题取 `<title>`；摘要基本不展示（description 仅作抓取参考）；缩略图抓取页面第一张 300×300 以上、非懒加载、同域 `<img>` 标签引入的图片（SVG 无效）。

**阶段一（先静态 meta）**：静态 meta + 首屏放一张规范首图，即可控制标题与缩略图。

**阶段二（后 JSSDK）**：接入已认证公众号 JSSDK，`wx.config` 签名通过后调用 `wx.updateAppMessageShareData`（好友对话卡）/ `wx.updateTimelineShareData`（朋友圈）完全自定义 title/desc/imgUrl；页面域名必须加入公众号 JS 安全域名。

## 二、分享卡文案与 og:image 尺寸

og:image 推荐 **500×400（约 5:4，PNG < 300KB）**，微信好友卡缩略图按此比例显示最完整；1200×630 会被裁边，仅在需要兼顾其他平台（微博/Facebook 等）时选用。

- 家长向｜标题：高中数学提分，先试听再决定｜摘要：一对一诊断薄弱点，免费试听一节，名额有限。
- 学生向｜标题：数学从90到130的提分路径｜摘要：题型拆解+每周定制练习，加老师微信免费领诊断。

## 三、二维码策略（页面内"扫码咨询"交互）

- 右下角悬浮按钮常驻（文案"扫码咨询"），全程可点。
- 点击弹出底部弹层：遮罩（点击关闭）+ 二维码大图 + 一键复制微信号 + 长按提示语。
- 长按识别提示语："长按上方二维码，选'识别图中二维码'加老师微信"
- 长按保存兜底提示语："长按可保存图片，到相册扫一扫也能添加"
- 二维码选型：**优先企业微信二维码**（加人无上限压力、抗风控、支持自动欢迎语）；个人微信有人格感但频繁加人易被限制；公众号二维码多一跳转化，不做主 CTA。

## 四、"一键复制微信号"技术要点

- `navigator.clipboard` 在微信内置浏览器（XWeb）内仅 HTTPS + 用户手势下部分可用，安卓上不稳定，不能单独依赖。
- 必须降级方案：创建隐藏 `<textarea>` 填入微信号 → `select()` → `document.execCommand('copy')`。
- 复制成功 toast："已复制，去微信搜索添加吧"；失败 toast："复制失败，请手动输入下方微信号"。
- **微信号必须明文展示**（如 `teacher_math001`）：复制失败时用户可照抄手动搜索添加，这是兜底主路径；纯数字微信号更易手输。

## 五、防封/防拦截检查清单

避免以下词和行为（易触发微信安全提示）：
- 诱导分享话术：转发到群、集赞解锁、分享后可见；
- "点击下载 APP"、下载引导；
- 拉起外部浏览器/APP；
- 多级域名重定向、过长短链链；
- 堆砌"加微信领资料"类高频敏感词。

域名要求：**必须 ICP 备案并启用 HTTPS**。未备案域名在微信内打开会提示"非微信官方网页，确认后继续"，二次确认造成大量流失；备案域名最稳。

## 六、iOS/Android 微信差异清单

- 字体渲染：两端字体差异大 → line-height ≥ 1.6，预留换行空间；
- clipboard 行为：iOS 较稳、安卓不稳 → 统一走 execCommand 兜底；
- 长按菜单：iOS 长按图片可直接"识别二维码"，部分安卓机型需先保存再扫一扫 → 提示语两者都覆盖；
- safe-area：弹层按钮 `padding-bottom: calc(16px + env(safe-area-inset-bottom))`；
- fixed 弹层：iOS 弹层弹出时需同时 `body{overflow:hidden}` 防背景滚动穿透。

## 七、转化路径优化

三次触点布局：
1. 首屏头部大 CTA 按钮，锚点直达底部咨询区；
2. 中段成绩/成果展示后插入一条文字 CTA；
3. 底部完整咨询区（二维码+微信号+复制按钮），叠加全程可达的悬浮按钮。

后续运营建议：添加老师微信后自动回复——"本周六 10:00 可约免费试听，回复【年级】帮你排时间"。用具体时间锚点（本周六 10:00）降低家长决策成本，并以前置收窄的选项（回复年级）推进对话。
