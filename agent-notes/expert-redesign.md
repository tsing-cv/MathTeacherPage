## 0. 三条批评的病根诊断

- 批评一（选题没选对）：病根是**放着行业现成的常识词不用，自己生造抽象词**。教师圈、教辅圈、家长圈早有共同语言——「高考万变不离其宗」「高考数学就那几百道母题」，书店里就摆着叫《高考母题》的畅销教辅。家长听过这个词、信过这个理，而现标语「体系」「地图」全是要从零解释的造词。全页主题必须落在「母题」上：它自带圈层权威感（行话）、家长常识感（听说过的词）、可数可验证（不是空概念，是 300 个实体）、以及最关键的利益承诺——**学一道母题，会一串变式，以一敌百**。
- 批评二（首页空洞）：主标语是结论，不是事实。刷手机的高三家长 3 秒内需要的是「数字 + 行话 + 悬念」，现在一条都没有。
- 批评三（试听老套且是假承诺）：页面在替老师编造一个不存在的产品（「完整正课试听 + 诊断图 + 15 分钟沟通」三件套）。2026 年的家长被漏斗话术训练了十年，「预约 / 登记 / 面谈」直接触发防御；承诺兑现不了的东西，是在透支唯一资产——这位老师本人的可信度。

## 一、母题化主题设计（本次重做的地基）

### 1. 为什么「母题」对这单案例是天然的主场

这个案例最硬的资产不是「教学经验」，是一条**别人抄不走的生产线**：

> 20 年（2006–2025）18,000+ 道真题逐题手拆 → 归纳出 300+ 道母题 → 每道母题下挂它的历年变式。

「母题」正是这条生产线的名字。换句话说：**换任何一个机构、任何一个老师，这个主题都立不住；只有他立得住。**主题与资产咬合到这个程度，页面就不需要修辞来帮忙。

对「独立教师 + 手写教案 + 板书推导」这个主体为什么天然成立：
- 机构的教材是编辑部流水线产物；300 道母题是一个人 20 年逐题拆出来的**私有台账**——母题库天然是独立教师的手搓资产，机构味绝缘。
- 手写教案 = 每道母题先写透几页纸再上课；直播板书 = 母题推导的现场，一步不跳。产品每个真实特征都能落到「母题」上，不需要编一个字。

两代人如何秒懂：
- 家长（35–50）：书店见过《高考母题》，自己说过「万变不离其宗」。页面上第一次有人把那个虚的「宗」数给他看——**300 道，道道有名有姓有台账**。从玄学变账本，信任瞬间完成。
- 学生（15–18）：他们的考场高光时刻就是那一句「这题我见过」——认出母题的瞬间。页面的承诺正好落在这个瞬间上。

传播记忆点 / 谈资：
1. 数字对撞句「18,000 道 → 300 道」自带复述性：家长转述给同事只需一句话。
2. 「学一道，会一串」六字，复述零成本，是全页利益的最低压缩。
3. 学生考场的口头禅从「这题没见过」换成「这是哪道母题」——口头禅即品牌。
4. 老师的人设句：「万变不离其宗。我教的，就是那个宗。」

使用纪律（母题主题的三条红线）：
- 「母题」是教辅圈常用词，书店里一排同名书。差异化必须落在动词事实上——「逐题拆过、台账可查、直播板书」，否则会被当成又一本《高考母题》。
- 18,000 / 300 两个数字上线前必须与台账对齐（能翻出行数）；对不齐就整体降格为「上万道 / 三百来道」。数字是这个主题的承重墙，不许带 ※ 上线。
- 不承诺「背 300 道就够」。高考会长新枝——页面要明说：母题是宗，宗上还会长新枝，所以第四阶才是「化题」。这句话既防抬杠，又自然引出课程体系。

### 2. 主标语：三个候选，逐一裁定

| 候选 | 标语 | 论证 | 裁定 |
| --- | --- | --- | --- |
| ① | **18,000 道真题，拆出 300 道母题** | 数字对撞即论证：前一个数字是 20 年苦功（可信度），后一个数字是结论（松弛感）；「拆出」是老师的手艺动词，直接接住页内「真题实拆」区；「母题」二字当场种进家长脑子，全页随后兑现这个词 | **选定** |
| ② | 把二十年高考，教回 300 道母题 | 动作在「教」，有老师本人温度；但少了海量对撞的 3 秒冲击，「教回」还要半秒才懂 | 落选，降为导师区可用句 |
| ③ | 万变不离其宗，宗就 300 道 | 俗语接口最亲，家长会心一笑；但「母题」关键词缺位，概念要靠副标语补，且「宗」偏文气，学生端略隔 | 落选，其精神并入导师引言 |

【为什么选 ①】高三家长 3 秒划过，接住的顺序是：一个吓人的海量数字（她孩子正在里面泡着）→ 一个松弛的可数数字（300）→ 一个行话（母题）→ 「拆出」的手艺人。冲击、 relief、权威、人味，四件事一句全做完了。

### 3. 三大思维模型的母题化重述（原名保留，解释全部换轨）

| 原模型名 | 母题化身份 | 页面上的一句话解释 |
| --- | --- | --- |
| 结构透视 | **认出母题** | 题面怎么换，骨架不变——一眼认出它是 300 道里的哪一道 |
| 命题溯源 | **看穿怎么变** | 站到出题人一侧：这道母题今年动了哪个数、换了哪层皮 |
| 迁移网络 | **挂回母题** | 每道变式做完，挂回母题身上；一串变式长在一道母题上，认一知百 |

页面呈现：白话身份（认出母题 / 看穿怎么变 / 挂回母题）做大字，原模型名降为小字注（照顾老学员话语）。
【为什么】家长记不住「迁移网络」，记得住「挂回母题」；术语留给课堂，人话留给招生页——三个动作连起来正好是「认出 → 看穿 → 挂回」，一条母题学习的完整动线。

### 4. 拾阶四阶段的母题化重述（识题 / 拆题 / 选题 / 化题 原样保留）

| 阶段 | 母题化含义 | 一句话表述 |
| --- | --- | --- |
| 识题（高一） | 认出母题 | 见题先问「这是哪道母题」——新题当面认成旧题 |
| 拆题（高二） | 拆开母题 | 把母题的解法拆成有顺序的小步，顺步走，不硬啃 |
| 选题（高三） | 考场认变式 | 认出母题、判断变式深浅，先拿会的——会做的都拿住 |
| 化题（考研） | 母题迁去新场 | 大学题也是高中母题的变式；新场景自己推得出解法 |

配套命名裁定：课程体系名由「拾阶·数学思维贯通计划」改为**「母题四阶计划」**，口头简称**「母题班」**，工作室名「陈老师数学」不变。
【为什么】「拾阶」是零信息的生造词；「母题四阶」四个字里有两个是资产（母题）一个是结构（四阶）——名字自己会说话，家长转述「孩子在母题班」时，招生的种子已经种下。

### 5. 考点频次图的旁白母题化

原图旁白「频次不是题库，是地图」→ **「频次的背后，是母题的分布——哪个板块母题密、哪几道年年出变式，一图看穿。教学顺序按它排：母题密的先立，每章例题都从母题里选。」**

【为什么】把统计图从「我研究很多」的证据，升级为「母题库真实存在」的索引——家长看不懂频次，但看得懂「有分布、有台账」。

## 二、新标语体系（母题语言内）

### 主标语（已裁定，见第一部分）

**「18,000 道真题，拆出 300 道母题」**

### 副标语（29 字）

**「近二十年真题逐题拆过，归根是 300 道母题——每道，挂着它的历年变式。」**

【为什么】主标语给冲击，副标语立刻补上母题的定义与利益（挂着变式＝学一道会一串的机制），家长 5 秒内完成从「什么意思」到「哦，值」的闭环。

### 点题句（Hero 小字，6 字）

**「学一道，会一串。」**

【为什么】把「以一敌百」翻译成两个动作，45 岁母亲和 16 岁学生同时秒懂；这是全页利益的最小压缩，也是日后家长转介绍时的原话。

### 全页区块标题母题化改写清单（11 处，均保留原信息功能）

| # | 区块 | 现标题 | 新标题 | 为什么 |
| --- | --- | --- | --- | --- |

| 2 | 导师介绍 | 先手写教案，再开口讲课 | 300 道母题，是怎么拆出来的 | 把资历从形容词（资深、专注）换成过程（拆出来），真人感与工作量同时立住 |

| 9 | 适合谁 | 这门课适合谁，不适合谁 | 谁适合来，谁先别来 | 保留坦诚筛选骨架，语气更冲——敢赶人的页面才像真人 |
| 10 | FAQ | 家长最常问的三件事（实际四件，数量还写错了） | 您想问的，我先答了 | 主动亮牌式透明，顺手修掉数量对不上的事实错误 |
| 11 | 底部转化 | 和陈老师聊聊 | 来拿讲义，或者来看一节课 | 把社交请求（聊聊）换成取货动作（拿、看），压力归零 |

【为什么】主题词用在内容标题，导航是路牌——路牌要无聊，这是可用性，不是文风。

## 三、2026 去套路转化机制（替代「预约试听」）

三原则：**价值前置（先看货）、零压力（全页不出现预约 / 报名 / 登记）、可履约（只承诺老师真能兑现的东西）。**

### 第 1 层：页内即时看货（不需要加微信，零门槛）

把「真题实拆」区块升级为看货入口：
- 在左右对比卡之下，嵌入 1 条 3–5 分钟真实课堂回放切片（从现有全程回放里剪，打码学生昵称，标注录制日期），页内直接播放。最好选一条「母题 + 变式」的完整片段——家长亲眼看到「一道题怎么被认出是哪道母题」。
- 区块尾行 + 按钮：
  - 文字：「这是本学期在拆的母题之一。口说无凭，上面有 3 分钟课堂实录，板书一步没跳。」
  - 按钮：**「看一段上课录像（3 分钟）」**

【为什么】2026 年家长对文字承诺已经免疫，对「敢放原片」无法免疫——录像即证据，页面自己完成销售，不需要任何人开口。

### 第 2 层：直接进正式课堂（替代虚构的「试听课」）

机制：每个班每周固定留 **1 个「看课位」**——孩子直接进真实直播间的「最后一排」，听完整 90 分钟，不收费、不登记姓名、课后不追问。这不是虚构试听课，是把真产品开放一次旁听。

- 课表公示块（放在真题实拆之后、母题四阶之前，做成「本周上课」小黑板）：

```
本周上课（每周一更新）
周四 19:30  高三 · 导数母题：三个动作收边界 —— 看课位 余 1
周六 09:00  高二 · 圆锥曲线的三道核心母题 —— 正常开课
周日 15:00  高一 · 第一课：什么叫母题 —— 可看回放
```

- 区块说明行：「课表每周一换，来的都是真课；看课不用报名，看完我也不问。」
- 按钮：**「周四 19:30 有课，来看最后一排」**

【为什么】「试听」是销售词、「看课」是用户词；「最后一排」把零压力写成了画面（像家长去学校听课）；课表公示直接回答「这老师真的每周在上课吗」这一独立教师最致命的隐性疑问，也把「本周什么时候有课」的透明化做成页面常态而非客服问答。

### 第 3 层：微信 = 取货通道（不是销售入口）

微信的定位全页统一为「领讲义 / 进教室」的配送通道：
- 底部按钮：**「微信找我拿讲义」**——讲义是老师每周真实有的东西（母题讲义），100% 可履约。
- 微信自动回复规则（老师设置一次即可）：回「讲义」→ 自动发当周母题讲义 PDF + 本周课表图；回「看课」→ 发直播间链接 + 看课须知；回「卷子」→ 提示拍照发来，老师看一眼说真话。
- 话术纪律：发完东西不追问、不连环追问。「看完课我不追问」五个字写在页面上，是最高的反漏斗声明。

### 上线前置条件（可履约的账单，老师每周合计不超过 30 分钟）

1. 每周剪 1 条 3–5 分钟回放切片（选一条母题片段），标日期。
2. 每周一更新课表块与看课位余量（静态文字即可，不求自动化）。
3. 微信设好「讲义 / 看课 / 卷子」三个自动回复。
【为什么】页面上每个承诺都有实物对应，这就是「可履约」的全部成本——比维持一个虚构的试听课便宜得多，也比任何话术都值钱。

### 全页禁用词表（给后续所有改文案的人）

预约、报名、登记、咨询、试听、封班、满员即止、名额有限、限时、大礼包、独家、体系、贯通、赋能、闭环、抓手、颗粒度、素养、大招、秘籍、秒杀、押题、必考、命中率。
【为什么】前半是漏斗腔，中段是 AI 腔与行业黑话，最后三个（押题 / 必考 / 命中率）是母题主题最容易滑进去的教辅夸大腔——「母题」讲的是规律，不是内幕，一字之差就从账本变玄学。

## 四、全页「反感点」审计（逐区块，现状 → 问题 → 替换）

### Hero 区

1. 「把数学学成体系，把真题读成地图」→ 抛弃行业常识词「母题」，自造双抽象 → **「18,000 道真题，拆出 300 道母题」**。
2. 「近二十年真题逐题拆解……一套体系贯穿始终」→ 筑基 / 进阶 / 体系 / 贯通，黑话四连发 → **「近二十年真题逐题拆过，归根是 300 道母题——每道，挂着它的历年变式。」**
3. 「数学不是题海，是结构。」→ 口号腔，「结构」看不见 → **「学一道，会一串。」**
4. 「预约试听直播课」→ 假承诺 + 漏斗词 → **「看一段上课录像（3 分钟）」**。
5. 「8 人小班封班 · 满员即止」→ 逼单腔，2026 家长的条件反射是划走 → **「8 人一班 · 每周留 1 个看课位」**（同样的稀缺，换成可核实的事实）。
6. 「18,000+ 道 ※」「300+ 类 ※」→ 带「※示意」挂网等于自曝数据是编的；且原四格互不相关、堆砌感重 → 换成 Hero 装配的四格（见第五部分：两个数字从「炫耀」变成「对撞论证」）。上线前数字必须与台账对齐，对不齐就降格「上万道 / 三百来道」。
【为什么】一颗 ※ 毁掉全页信任：要么给真数，要么不给数。

### 写给家长的信

7. 「我可以负责任地说」→ 权威说教腔 → **「十八年看下来，这话我敢说：」**
8. 「这门课要教的，就是那套一直没人教过他的方法。」→ 略空 → **「孩子刷不完的题，归根就那几百道母题——这套没人教的东西，恰好是我每天在教的。」**
（信的故事本体——初中拔尖、高中月考砸、补课无效——是全页最好的内容，保留，只换标题与上述两句。）

### 痛点 / 教研体系区

9. 「——同一件事的两面：不是不努力，是从没人教过他『怎么学数学』。」→ 修辞铺垫过长 → **「孩子不是学不动，是一直在跟变式赛跑，从没见过母题。」**
10. 三大模型名「结构透视 / 命题溯源 / 迁移网络」→ 造词黑话，家长记不住也念不出 → 页面大字改白话三步：**认出母题 / 看穿怎么变 / 挂回母题**（原名降为卡片小字注），解释句见第一部分第 3 条。
11. 「频次不是题库，是地图。」→ 旧主题残留 → **「频次的背后，是母题的分布——哪几道母题年年出变式，一图看穿。」**
12. 「※ 上图为示意数据，正式版以教师逐年登记台账为准」→ 挂网的自首书 → 上线前换成真实台账数据（18,000 / 300 都要能翻出行数），否则整图撤下。

### 导师区

13. 全段第三人称「他」→ 机构代写手势，页面是老师自己的却像别人介绍他 → **全页改第一人称「我」**。
14. 「900+ 累计学员 ※」→ 最不可核验的堆砌数 → 换成 **「0 个销售」**（回微信的只有我本人）。「18 年教龄」「11 届毕业班」保留，但上线前须能出示佐证（成绩册 / 毕业照）。
【为什么】「0 销售」用数字说人话，把独立教师的劣势（没规模）翻译成优势（没人打你电话），是全页反机构腔的签名句。
15. 引言「别急着背结论，先看清它是怎么长出来的。」→ 略文艺 → **「万变不离其宗。我教的，就是那个宗。」**（家长俗语 + 老师担当，一句立住人设）
16. 「在他看来，解法应该让学生亲眼看着它一步步长出来。」→ 第三人称 + 修辞 → **「一步一步，让学生亲眼看着变式拆回母题。」**

### 课程 / 卖点区

17. 「拾阶 · 数学思维贯通计划」→ 生造名 + 黑话双连 → **「母题四阶：从识题到化题」**。
18. 「本周思维模型，从真题里长出来」→ 模型黑话 → **「本周的母题，从两道真题里逼出来」**。
19. 卖点名「实时互动」→ 功能词，平 → **「当场问，当场通」**。
20. 「答疑闭环」→ 行业黑话标本 → **「问题不过夜」**。
21. 「板书推导」→ 可保留，或更狠：**「板书不跳步」**。
（「录播课教你这题这么做，直播课教你卡住了怎么办」这句是全页现有最佳金句，保留。）

### 反馈区

22. 「变化，发生在思路里」→ 抽象 → **「孩子开始说：这题我见过」**。
23. 「※ 反馈经授权节选；个体体验因人而异，不构成任何效果保证」→ 法务免责压在表扬正下方，阴阳怪气感 → 合规文字保留但**移到页脚**与既有 trust 小字合并。
【为什么】法务免责是必要的，但位置是情感设计：压在动情内容正下方等于自己拆台。

### 适合谁

24. 「拿不准？加微信聊十分钟」→ 社交压力 + 仍在漏斗里 → **「拿不准，把孩子最近一张卷子拍给我，我看一眼说真话——不合适我直说。」**
【为什么】「拍卷子」是可履约的看货动作（老师本来就会看卷，还能顺手做「认母题」示范），比「聊十分钟」具体一百倍。

### FAQ

25. 标题「家长最常问的三件事」实际挂了四件 → 事实错误 → **「您想问的，我先答了」**（数量不再写死）。
26. 「留给走神的空间很小。」→ 系统承诺腔 → **「8 个人的班，谁走神我看得见，我会直接点他名。」**
【为什么】承诺「防走神机制」是机构话术，「我会点他名」是活人承诺——只有真人敢这么说话。
27. 「具体数字试听后面谈」→ 试听不存在 + 价格钩子，2026 家长最反感的一句 → **「按阶段付费，一节课折合 X–X 元，区间写在明处；看完录像、看完课，再谈也来得及。」**
【为什么】敢写价格区间的小透明赢得的信任，远大于「面谈」钩子钓上来的咨询量。
28. 建议新增一条 FAQ（母题主题必答题）：**「背下 300 道母题就够了吗？」→「不够，也不背。母题是宗，宗上还会长新枝——高考每年都有没见过的新变式。所以前三阶认、拆、选，第四阶是化：新变式自己推得出解法，才算学成。」**
【为什么】主动回答比被家长在心里质疑强；这一问一答还顺手把四阶段重新卖了一遍。

### 底部转化区

29. 「免费试听不是缩短版体验课，而是一节完整的正式班课 + 诊断图 + 15 分钟沟通」→ 整段是替老师虚构的产品，全部撤下 → 换成三层转化的实物清单：①页内 3 分钟母题录像 ②每周 1 个看课位 ③微信回「讲义」领当周母题讲义。
30. 「每班 8 人封班，试听位按周开放，满员即止。添加微信回复【年级】帮你排期。」→ 逼单 + 排期话术双杀 → **「本周看课位：高三班余 1（周四 19:30）。微信回『看课』，我发直播间链接；回『讲义』，先发你这周讲义。」**
31. 「咨询 · 试听」（顶栏按钮与悬浮球）→ 全页最高频曝光位放了个销售词 → 顶栏 **「本周课表」**、悬浮球 **「看一段真课（3 分钟）」**。
32. meta / og 描述里的「免费试听完整正课」→ 假承诺进了微信转发卡，传播半径最大的位置 → 随第五部分 og 方案一并替换。

## 五、Hero 区最终装配（母题语言体系内）

| 槽位 | 文案 |
| --- | --- |
| 眉题 | 独立数学教师陈老师 · 8 人小班直播 · 高一至考研 |
| 主标语 | **18,000 道真题，拆出 300 道母题** |
| 副标语 | 近二十年真题逐题拆过，归根是 300 道母题——每道，挂着它的历年变式。 |
| 点题句 | 学一道，会一串。 |
| 主按钮 | 看一段上课录像（3 分钟）→ 锚至真题实拆区录像 |
| 次按钮 | 本周课表 → 锚至课表公示块 |

数据信任条四格（全部可核实，无一需要 ※）：

| 数字 | 说明 |
| --- | --- |
| 18,000+ | 道真题逐题拆过，台账可查 |
| 300+ | 道母题，道道挂着历年变式 |
| 8 人 | 一班；每周留 1 个看课位 |
| 0 销售 | 回微信的只有我本人 |

【为什么逐格】①②不是两个炫耀数字，是一组对撞论证——海量在左、可数在右，主标语在四格里再落地一次；③稀缺感从逼单话术变成可核实事实；④反机构腔签名句，数字 0 比任何形容词都响。

配套 meta（微信转发卡，一并替换）：

- `<title>` / og:title：18,000 道真题，拆出 300 道母题 —— 陈老师高中数学（8 人小班直播）
- og:description：高考万变不离其宗。近二十年真题逐题拆过，归根 300 道母题，每道挂着历年变式——学一道，会一串。页内可看 3 分钟上课录像与本周课表，不用加微信。

**3 秒检验（上线前自查）**：高三家长拇指划过首屏，应依次接住——一个海量数字（18,000，她孩子正泡在里面）、一个可数数字（300）、一个行话（母题）、一个敢放录像的老师（按钮）。四件东西全在第一视口内，即合格。

## 收尾：这套设计的全部赌注

赌的不是文案技巧，是一件事：**把「母题」从教辅封面上的一个玄学词，变成一个有台账、有录像、有人背书的实体。**数字对撞负责让人 3 秒停下，母题概念负责让人觉得自己听懂了，三层转化负责让人不用被说服就走进来。机构页缺的从来不是修辞，是一个敢把货摆在明处的活人。
