# 陈老师 · 高中数学招生单页（串版）

一个无框架依赖的单文件招生页面（`index.html` + `assets/` 图片）。
设计基准 iPad 4:3（1024×768），同时适配手机微信内置浏览器（375–430px），
含微信转发卡片（Open Graph）配置、二维码长按识别、微信号一键复制。
外链只有两处老师自有内容（小红书主页 / 真题库在线版），均新窗口打开。

> **页面说服结构**（主题一句话：**18,000 道题，串成 300 串——学一道，会一串**）：
> 首屏数字对撞标语 + **真题函数曲线动画**（f(x)=(x−2)eˣ+(x−1)²，即页内实拆的 2016 全国 I 卷理 21 取 a=1，终态标两零点）+ **三张数据卡**（18,000→300 论证卡 / 3–5 人小班 / 8 年教龄；「0 销售」移至底部联系区）
> → **写给家长的信**（孩子刷不完的题，其实只有 300 串；含独立金句块「方法没换，学科已经换了」）
> → 导师介绍（第一人称「我」+ 资历锚点 8 年/3 届两格 + **拆解链四节点**：18,000 道→手写拆解→六大板块→300 串 + **小红书日常拆题**单卡 + 拆题样例图）
> → 题串库：双列痛点 + 白话三步（认出根/看穿怎么变/挂回串上）+ 考点频次图（**真题库真实统计**，见下文红线表；首条亮金 + 底部刻度 + 图表要点）
> → **真题实拆**（2016 全国 I 卷理科 21 压轴导数题：背步骤 vs 认出根对照 + 页内 3 分钟课堂录像 + **根题谱系图**——同根家族 2017/2018/2021/2022/2025 全国 II 18/2025 天津 20 逐年下挂，实查真题库 + 真题库在线版入口横幅）
> → 课程区：**按教学规律分四段**（同步·高一高二 / 一轮·高三上 / 二轮·高三下 / 延伸·考研竞赛强基，每段=可观察变化+出口标准）+ **90 分钟时间配比条**（先讲作业 10′ / 认根拆题 30′ / 逐行板书 30′ / 当堂演练 20′，两头都是「验」）+ 90 分钟时间线 + 课前到课后横带（**按周**汇总反馈）+ **学会的四个标准**（懂/会/对/熟四步逐级缩进成阶梯，每步带「怎么验·没过怎么办」小字）+ 进班第一个月四步
> → 深底过门金句带（孩子卡住的那一步，才是最该讲的那一步）
> → **班型与价格**（三档明码、三线城市梯度：3–5 人小班 100–150 / 一对一 300–450（约 3 倍小班）/ VIP 签约课 8,800 元/学年起——均为建议占位值，上线前必改真实定价；小班主推卡暗金顶边+实底徽章）
> → 教研现场「300 串的产地」（**七图证据链**：手写教案/真题批注/考点台账/直播板书/批改痕迹/学生按串归类笔记 + **学习反馈样例横幅**）
> → 学员反馈（**5 条六要素提分案例**：起点→终点分数标签 + 时长，各含中途回落与归因；+ 1 张微信聊天还原卡）→ **谁适合来，谁先别来**（坦诚筛选）
> → FAQ 15 问（走神/粗心/作息/平台/同班水平/一个人带得过来吗/与学校讲法不一致/独立背书/基础差/插班/学费/退费/AI「考试机器」/背 300 串够吗/差异化压轴）
> → 底部联系（微信号复制 + 二维码长按；弹层触发点共 **2 处**：顶栏按钮、悬浮球）

## 二、本地预览

直接双击 `index.html` 即可打开；但**二维码长按、分享卡等微信行为需通过 http 访问**，推荐：

```bash
cd MathTeacherPage
python3 -m http.server 8765
# 浏览器访问 http://localhost:8765/
```

用 Chrome 开发者工具「设备模拟」选 iPad（1024×768）和 iPhone（375）各看一遍。

## 四、每周运营账单（页面承诺的可履约成本）

页面承诺的东西对应每周要做的事——**做不到就不要让页面上线**：

1. **每周剪 1 条 3–5 分钟回放切片**（选一条一串的根与变式片段，标日期）→ 覆盖 `assets/clip-daoshu.mp4`；
2. **按周汇总学习反馈**：课中答题记录、限时演练得分、当周认下的串，汇总发家长（页面多处承诺「按周汇总」，样例图见教研现场末图）——三五人的班，每周约十几分钟；
3. **作业批改**：拍照提交、逐题旁批（教研现场有批改痕迹样例图，承诺了「不是打勾叉」）；
4. **日常输出块（小红书/真题库在线版）**：自媒体为老师已有运营，页面只做展示对接；页面写的是「常年有新内容」，若实际断更超过一个月，把入口撤下或降格措辞。

## 五、全页禁用词表（后续所有改文案的人必读）

> 预约、报名、登记（个人信息义）、咨询、试听、封班、满员即止、名额有限、限时（优惠义）、
> 大礼包、独家、体系、贯通、赋能、闭环、抓手、颗粒度、素养、大招、秘籍、秒杀、押题、必考、命中率

前半是漏斗腔（2026 年家长被训练了十年，直接触发划走），中段是行业黑话，
最后三个（押题/必考/命中率）是「串」主题最容易滑进去的教辅夸大腔——
**串讲的是规律，不是内幕**。改文案时如需制造稀缺，用可核实的事实替代，不写逼单话术。

另：不写「稳上 XX 分」「平均提分 XX」类承诺句（提分区间只出现在学员反馈的真实数据标签里，且带「不构成效果保证」小字）；「当日回」「每讲一份报告」这类写不过来的承诺不写，统一口径是「课中留痕 + 按周汇总」。

## 六、部署（微信可访问的前提）

**微信内打开要求：已 ICP 备案的域名 + HTTPS。** 推荐两条路线：

1. **对象存储静态托管（推荐，年成本几十元）**
   腾讯云 COS / 阿里云 OSS 开启「静态网站」，绑自定义域名 + 免费证书，
   上传 `index.html` 和 `assets/` 即完成。
2. **轻量云服务器**：任意静态服务器（nginx / `python3 -m http.server` + systemd）。

> GitHub Pages / Vercel 等境外托管在微信内会被拦截或极慢，只适合自己预览。
> 视频文件较大（几十 MB 内皆可），对象存储注意开启 Range 请求支持以支持拖动进度条。
> 部署后把 `<head>` 里 `og:image` 的相对路径 `assets/og-cover.png` 改成**带域名的绝对网址**——微信抓分享缩略图只认绝对网址（代码内有★注释标记）。

**验收步骤**：手机微信打开链接 ① 右上角「…→发送给朋友」看卡片图是否正常；
② 长按底部二维码能否识别；③ 点「复制微信号」去微信粘贴验证；④ 播放页内录像是否流畅；
⑤ 顶栏「加微信」按钮、右下悬浮球——2 处都应弹出联系方式抽屉，ESC/遮罩可关；
⑥ 点「真题库在线版」「小红书」外链，确认新窗口打开且指向正确。

## 八、合规要点（已内置，改动时勿破坏）

- 页脚合规小字：数据出自逐年登记台账、可查验；反馈经授权节选、不构成效果保证——保留；
- 文案已避开「提分/保过/第一名/押题/必考」等《广告法》与教辅夸大风险词，后续同样回避；
- 外链仅限老师自有内容（小红书主页、真题库在线版），新窗口打开、无诱导性文案——新增外链前先确认是自有内容；
- 字体全部为系统自带字体（宋体/苹方等），无字体版权风险；图片需用自拍素材，忌网络图；
- 课堂录像必须打码学生昵称、不出现可辨识人脸。

## 九、技术特性备忘

- 单文件、无框架、无 CDN、无网络字体——大陆网络一次请求完成渲染；
- 动画仅三处（首屏曲线描画 / 数字滚动 / 条形图伸展），系统「减弱动态效果」时全部直出终态；
- 复制微信号用 `execCommand`（必须在点击手势同步调用，微信内核最稳），失败自动提示手动输入；
- 底部弹层已处理 iPhone 安全区（`env(safe-area-inset-bottom)`）与滚动穿透；
- 二维码为 `<img>` 位图且未加 lazy——这是微信长按识别的硬性条件，勿改背景图/SVG；
- `<video>` 加了 `playsinline`（微信内联播放）；`controls` 原生控件，无 JS 依赖；
- 新增占位图必须同步补 `gen_assets.py` 生成函数（页面引用与生成器保持一一对应，防 404）。
