第一章 集合与常用逻辑用语

必修第一册 · 人教A版2019新课标

集合的交集运算

核心公式

A \cap B = \{x | x \in A \text{ 且 } x \in B\}

两个集合的交集由所有同时属于集合A和集合B的元素组成。交集运算满足交换律和结合律。

集合的并集运算

核心公式

A \cup B = \{x | x \in A \text{ 或 } x \in B\}

两个集合的并集由所有属于集合A或集合B的元素组成。并集运算满足交换律和结合律。

德摩根定律

重要定理

\overline{A \cap B} = \overline{A} \cup \overline{B}

\overline{A \cup B} = \overline{A} \cap \overline{B}

德摩根定律描述了集合运算中对偶性的关系，在逻辑推理和概率论中有重要应用。

基本不等式

核心公式

a + b \geq 2\sqrt{ab} \quad (a, b > 0)

两个正数的算术平均数不小于它们的几何平均数。等号成立条件：当且仅当 a = b 时取等号。

指数运算法则

基础公式

a^m \cdot a^n = a^{m+n}

\frac{a^m}{a^n} = a^{m-n}

(a^m)^n = a^{mn}

指数运算的基本法则，适用于所有实数指数。这些法则是指数函数和对数函数的基础。

对数运算法则

基础公式

\log_a(MN) = \log_a M + \log_a N

\log_a\frac{M}{N} = \log_a M - \log_a N

\log_a M^n = n\log_a M

对数运算的基本法则，将乘除运算转化为加减运算，简化复杂计算。
